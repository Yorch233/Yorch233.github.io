# MiSans

This site uses MiSans by Xiaomi Inc. The complete variable font is bundled locally.

- Official page: https://hyperos.mi.com/font/zh/details/sc/
- Official source archive: https://hyperos.mi.com/font-download/MiSans.zip
- Source file: MiSansVF.ttf (weight axis 150–700)
- Web asset: MiSans-VF.woff2, losslessly WOFF2-compressed from the complete source font; no glyph subsetting or outline changes.
